# Few-Shot Text Analysis

A Python toolkit for performing few-shot learning analysis on text data using Large Language Models (LLMs). This project enables you to predict target attributes (like CTR, CVR) from ad examples using few-shot prompting with both remote API and local LLM clients.

## Features

- **Few-Shot Learning**: Configure and run few-shot prompts with customizable examples
- **Multiple LLM Clients**: Support for both remote API (HuggingFace) and local LLM clients
- **Parallel Processing**: Multi-threaded processing for API calls (configurable)
- **Accuracy Analysis**: Calculate and visualize prediction accuracy against ground truth
- **Dataset Generation**: Generate synthetic datasets using LLM-based data augmentation

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set up environment variables:
   - Create a `.env` file
   - Add your API keys:
     ```
     HF_TOKEN=your_huggingface_token_here
     OPENAI_KEY=your_openai_key_here  # Optional, if using OpenAI
     ```

### Basic Usage

The `main.py` script demonstrates the core functionality:

1. **Define Target Attributes**: Create `TargetAttribute` objects that specify what you want to predict:
   ```python
   CTR_llm = TargetAttribute(
       name="CTR_llm",
       prompt="Estimate the CTR from 0-100..."
   )
   ```

2. **Configure Few-Shot Learning**: Set up a `FewShotConfig` with:
   - Target attributes to predict
   - Input attributes for in-context learning
   - Number of few-shot examples
   - System instructions
   - Number of threads for parallel processing (API only)

3. **Process Data**: Use the `Processor` class to:
   - Load your dataset
   - Split into examples and prediction sets
   - Run predictions using the LLM client
   - Get predictions added to your dataframe

### What `main.py` Shows

The `main.py` script demonstrates:

- **Three configuration examples**:
  - CTR prediction only
  - CVR prediction only  
  - Combined CTR and CVR prediction

- **Data processing workflow**:
  - Loading data from `AdExamples.csv`
  - Splitting into training examples (50%) and prediction set (50%)
  - Processing predictions using `RemoteLLMClient`
  - Adding predicted values to the dataframe

- **Example output**: The processed dataframe will contain new columns with LLM predictions (e.g., `CTR_llm`, `CVR_llm`)

## Usage Examples

### 1. Running Predictions

```python
from config import FewShotConfig, TargetAttribute
from processor import Processor
from llm import RemoteLLMClient
import pandas as pd

# Define what to predict
CTR_llm = TargetAttribute(
    name="CTR_llm",
    prompt="Estimate CTR from 0-100..."
)

# Configure
config = FewShotConfig(
    target_attributes=[CTR_llm],
    icl_attributes=["ad_title", "image_description", "iab_category"],
    few_shot_examples_attributes=["ad_title", "image_description", "iab_category", "CTR"],
    nr_few_shot_examples=5,
    threads=4  # Parallel processing for API calls
)

# Process
df = pd.read_csv("./data/raw/AdExamples.csv")
df_examples = df.sample(frac=0.5, random_state=42)
df_predict = df.drop(df_examples.index)

processor = Processor()
client = RemoteLLMClient()

df_result = processor.process(
    df_processing=df_predict,
    df_examples=df_examples,
    client=client,
    config=config,
    model="openai/gpt-oss-20b:groq",
    temperature=0
)
```

### 2. Analyzing Accuracy

```python
from visualize import AccuracyAnalyzer
import pandas as pd

# Load predicted and measured data
df_predicted = pd.read_csv("./data/analysed/predictions.csv")
df_measured = pd.read_csv("./data/raw/AdExamples.csv")

# Analyze
analyzer = AccuracyAnalyzer()
results = analyzer.calculate_accuracy(
    df_predicted=df_predicted,
    df_measured=df_measured,
    target_attributes=["CTR_llm", "CVR_llm"],
    measured_columns=["CTR", "CVR"]  # Ground truth columns
)

# Print results
for attr, metrics in results.items():
    print(f"{attr}:")
    print(f"  MAE: {metrics['mae']:.4f}")
    print(f"  RMSE: {metrics['rmse']:.4f}")
    print(f"  R²: {metrics['r2']:.4f}")
```

## Configuration Options

### FewShotConfig Parameters

- `target_attributes`: List of `TargetAttribute` objects to predict
- `icl_attributes`: Column names used for in-context learning (input features)
- `few_shot_examples_attributes`: Column names to include in few-shot examples
- `system_instruction`: System prompt for the LLM
- `nr_few_shot_examples`: Number of examples to include in each prompt
- `threads`: Number of parallel threads for API processing (default: 1, only for remote clients)

### TargetAttribute

- `name`: Column name for the predicted value
- `prompt`: Description/instruction for what to predict

## LLM Clients

### RemoteLLMClient (API)

- Uses HuggingFace Inference API
- Requires `HF_TOKEN` environment variable
- Supports parallel processing via `threads` parameter
- Fast but requires internet and API credits

### LocalLLMClient

- Runs models locally using HuggingFace transformers
- Requires `torch` and `transformers` (commented in requirements.txt)
- No parallel processing (runs sequentially)
- Free but requires GPU/RAM resources

## Accuracy Metrics

The `AccuracyAnalyzer` calculates:

- **MAE (Mean Absolute Error)**: Average absolute difference
- **RMSE (Root Mean Squared Error)**: Penalizes larger errors more
- **R² (Coefficient of Determination)**: How well predictions explain variance

## Output

- Processed dataframes with predicted columns
- Accuracy analysis results

## Notes

- Parallel processing (`threads > 1`) only works with `RemoteLLMClient`
- Local clients process sequentially regardless of `threads` setting
- Make sure your API keys are set in `.env` file
- For local models, uncomment `torch` and `transformers` in `requirements.txt`
